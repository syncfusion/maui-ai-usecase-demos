# Tasks

Per-task instructions for the Syncfusion To Do List sample, following the
Gate-Based Harness approach documented in `../Harness.md`. Each module
groups independent tasks; each task is implementable, testable,
reviewable, and mergeable on its own.

| Module | Folder | Gate |
|--------|--------|------|
| 01 — Foundation | _(see `MauiProgram.cs`, `Resources/Styles/`, and the Module-01 tasks implicit in the original sample skeleton)_ | G-M01 |
| 02 — MyNotes | _(Module-02 tasks; not separately broken out — the first landed commit is the Module-02 milestone)_ | G-M02 |
| 03 — TaskCRUD | _(see `Features/EditNote/`, `Features/Notes/Services/`, and the bottom-input bar wiring)_ | G-M03 |
| 04 — Filtering | _(see `Features/Important/`, `Features/Reminder/`, `Features/Bin/`)_ | G-M04 |
| 05 — CustomLists | _(see `Features/CustomLists/`)_ | G-M05 |
| 06 — Search | _(see `Features/Search/`)_ | G-M06 |
| 07 — DragAndDrop | _(see `Features/Notes/Views/SidebarView.xaml.cs` and `NotesContentView.xaml.cs` for the gesture wiring)_ | G-M07 |
| 08 — Polish | [Module-08-Polish/](./Module-08-Polish/README.md) | G-M08 |
