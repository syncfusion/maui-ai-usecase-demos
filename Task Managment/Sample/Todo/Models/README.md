# Models

Domain models that describe the data shape used across the application.

- `User.cs` — Application user (Task 1-07 — `Database Setup`).
- `TaskList.cs` — Container for tasks (Task 1-07 — `Database Setup`).
- `TaskItem.cs` — Individual task (Task 1-07 — `Database Setup`,
  Task 4-01 — `Task CRUD Models`).

The `DTOs` subfolder holds transport-layer data transfer objects that the
Services layer exchanges with the UI layer.
