# Services

Application services consumed by the ViewModels through the .NET MAUI
dependency-injection container (registered in `MauiProgram.cs`).

Subfolder layout:

- `Interfaces/` — Service contracts (created in later Module-01 tasks).
- `Authentication/` — Sign-in / sign-up / forgot-password (Module 2).
- `Task/` — Task CRUD and assignment (Module 4).
- `Search/` — Search and filtering (Module 7).
- `Storage/` — Local SQLite persistence (Module 1, Task 1-07).
- `Infrastructure/` — Cross-cutting concerns (logging, navigation, etc.).
