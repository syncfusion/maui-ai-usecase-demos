# maui-ai-usecase-demos

This repository provides ready-to-use, AI-powered .NET MAUI use-case samples built with Syncfusion controls. It includes fully integrated implementations, best-practice patterns, and real-world scenarios to help developers quickly adopt and extend AI-driven features in their MAUI applications.

## Samples

| Sample | Description |
|---|---|
| [AI-Powered Maui Notes](AI-Powered%20Maui%20Notes) | A notes app built on the Syncfusion **RichTextEditor** with an AI writing assistant (Azure OpenAI) that edits selected text or a whole note in place, with Revert/Retry/Undo/Redo. |
| [AI-Powered Writing Assistant](AI-Powered%20Writing%20Assistant) | An AI-assisted writing experience pairing the Syncfusion RichTextEditor with the **AI AssistView** for paraphrasing, tone, grammar, elaboration, and shortening. |
| [Smart Article Generator](Smart%20Article%20Generator) | A source-backed article workspace using the Syncfusion **AI AssistView** and **MarkdownViewer** to generate structured Markdown articles with extracted resource links. |
| [AI-Solution-Samples](AI-Solution-Samples) | Additional samples, including **Context-Aware Suggestions** with the Syncfusion **AI AssistView** and Azure OpenAI. |

See each sample's `README.md` for setup instructions, prerequisites, and key APIs.
