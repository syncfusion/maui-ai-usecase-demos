# Education-Form-Generator-by-using-DataForm

This sample demonstrates an AI-powered dynamic education form generator built with **.NET MAUI** and **Syncfusion DataForm**. The application leverages **Azure OpenAI** to automatically generate education-specific form schemas and dynamically render the appropriate fields based on the selected education level.

## Overview

Educational applications frequently require different sets of fields for different education levels. For example, High School records may require SAT/ACT scores, while Bachelor's and Master's degrees require GPA, major, graduation year, and university information.

This sample uses Azure OpenAI to generate structured form schemas at runtime. When a user selects an education level, the AI service analyzes the request and produces a JSON schema containing the appropriate fields, validation rules, and input types. The generated schema is then rendered as an interactive Syncfusion DataForm.

The AI engine generates fields based on:

- Education level
- Institution information
- Program or major
- Enrollment status
- Start and end dates
- Academic performance metrics
- Graduation information
- Education-specific requirements such as SAT/ACT scores, GPA, country, state, and degree details

The application allows users to add multiple education entries, manage them independently, and build a complete education history through dynamically generated forms.

## Sample

```xaml
<dataForm:SfDataForm
    DataObject="{Binding Entry}"
    AutoGenerateItems="True"
    ValidationMode="LostFocus"
    CommitMode="PropertyChanged">
</dataForm:SfDataForm>
```

### Azure OpenAI Schema Generation

```csharp
var user = $"Create an education form schema for: {educationType}. " +
           "Cover institution, program, status, dates, and any metrics relevant to this level of education.";

var messages = new List<ChatMessage>
{
    new SystemChatMessage(PromptSystem),
    new UserChatMessage(user)
};

var chatOptions = new ChatCompletionOptions
{
    Temperature = 0f,
    ResponseFormat = ChatResponseFormat.CreateJsonObjectFormat(),
    MaxOutputTokenCount = 4096
};

var result = await chat.CompleteChatAsync(messages, chatOptions);
```

## How It Works

1. The user clicks **Add Education**.
2. An education level is selected from the picker.
3. The application sends the selected education type to Azure OpenAI.
4. Azure OpenAI generates a JSON schema describing the required form fields.
5. The schema is validated and converted into a DataForm structure.
6. A new education card is created.
7. The generated form is displayed to the user.
8. Users complete the form and mark the card as done.
9. Additional education entries can be added as needed.

## Azure OpenAI Configuration

Configure your Azure OpenAI settings before running the application:

```json
{
  "AzureOpenAI": {
    "Endpoint": "https://your-resource.openai.azure.com/",
    "ApiKey": "YOUR_API_KEY",
    "DeploymentName": "YOUR_DEPLOYMENT_NAME"
  }
}
```

The application validates Azure OpenAI credentials during startup and displays descriptive error messages if the configuration is invalid.

## Troubleshooting

### Invalid API Key or Endpoint

If the application reports an Azure OpenAI connection error:

- Verify the Endpoint URL.
- Verify the API Key.
- Confirm the Deployment Name exists.
- Ensure the deployment supports chat completion requests.

### Form Generation Failed

If form generation fails:

- Verify Azure OpenAI connectivity.
- Check deployment availability.
- Confirm the selected education level is supported.
- Review the application error message for additional details.

### Path Too Long Exception

If you encounter a "Path Too Long" exception while building the project, close Visual Studio, rename the repository folder to a shorter name, and rebuild the project.
