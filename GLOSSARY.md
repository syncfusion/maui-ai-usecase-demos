# Glossary

Terms used in this project, one line each. Code, specs and reviews use these words.

| Term | Meaning |
|---|---|
| Conflict | A pair of requirements that cannot coexist, oppose each other, violate one another, or create a business inconsistency. |
| Conflict detection | The only AI capability in this showcase: finding conflicts in one requirement set and explaining them. |
| Conflict result | The outcome for one requirement: conflict flag, conflicting requirement, explanation, and suggested resolution. |
| Hero grid | The Syncfusion DataGrid workspace where users review, filter, sort, and search conflict findings. |
| Requirement | One statement in the set, identified by a Requirement ID and a Requirement Text. |
| Requirement set | The imported collection of requirements stored for a single conflict analysis. |
| Suggested resolution | The stakeholder action the AI proposes for a conflict. It does not change the stored requirement. |
